## Overview
Track indoor particulate matter (PM2.5/PM10) and CO2 levels continuously.

Part of the **[RiseAhead Projects](https://github.com/Sahusaksham333/RiseAhead-Projects)** open-source collection (`PRJ-067`).

## Tech Stack
- ESP8266, PM2.5 Sensor, MQTT
