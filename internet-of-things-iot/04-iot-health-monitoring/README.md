## Overview
Monitor heart rate and SpO2 telemetry with threshold alerts for caregivers.

Part of the **[RiseAhead Projects](https://github.com/Sahusaksham333/RiseAhead-Projects)** open-source collection (`PRJ-064`).

## Tech Stack
- Arduino/ESP32, Pulse Sensor, MQTT
