## Overview
Measure overhead tank water depth and automate pump cutoff to stop overflow.

Part of the **[RiseAhead Projects](https://github.com/Sahusaksham333/RiseAhead-Projects)** open-source collection (`PRJ-070`).

## Tech Stack
- Ultrasonic Sensor, ESP8266, Web UI
