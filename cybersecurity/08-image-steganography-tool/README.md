## Overview
Embed and extract encrypted messages invisibly inside PNG pixel least-significant bits.

Part of the **[RiseAhead Projects](https://github.com/Sahusaksham333/RiseAhead-Projects)** open-source collection (`PRJ-038`).

## Tech Stack
