## Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/Sahusaksham333/RiseAhead-Projects.git
cd RiseAhead-Projects
```

### 2. Run Any Project
- **Python projects**: `cd python/<project-folder> && python main.py`
- **Frontend web apps**: Double-click `frontend/<project-folder>/index.html` in any browser (zero build step!)
- **Java projects**: `cd java/<project-folder> && javac *.java && java <MainClass>`
